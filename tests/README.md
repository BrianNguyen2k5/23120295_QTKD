# Thư mục Kiểm thử tự động (`tests/`)

Thư mục này dành cho project kiểm thử tự động (**xUnit**) sẽ được triển khai trong **Tuần 07** theo lộ trình thực hành:
- Kiểm thử đơn vị (Unit Tests) cho các quy tắc nghiệp vụ `CTR-01`, `CTR-02`, `CTR-03` và `US03` (`AC01..AC05`).
- Kiểm thử tích hợp (Integration Tests) cho luồng `Tạo Customer` $\rightarrow$ `Tạo Contract Draft` $\rightarrow$ `Bổ sung thông tin` $\rightarrow$ `Gửi trình duyệt (Submit)`.
